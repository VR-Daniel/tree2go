What it is

tree2go is one of many phylogenetic tree viewers and editors out there, so in that sense, it is just one option among many. What makes it different is that it brings together many of the customization options that other software offers, all in one place.

As someone who spends a lot of time making figures look good, I’ve often run into the same problem: no software is perfect. Some tools make certain types of edits easy, but then you have to move your figure to another program to do something else, or resort to code, which can be time-consuming and requires additional technical knowledge. The idea behind tree2go is to keep things simple.

tree2go runs directly in your browser, with or without an internet connection. It can be run directly from my GitHub repository or downloaded as a single HTML file that opens like any regular webpage. It is fully self-contained, meaning it does not rely on any external resources to work. It is free, open, and unrestricted: there is no registration or subscription, and all of its features are available to everyone.

At just 380 KB, tree2Go weighs less than half as much as DOOM, one of the most iconic video games ever made. And if DOOM has run on ATMs, calculators, printers, and even pregnancy tests, then pretty much any modern piece of hardware should be able to run tree2Go.

How to use it

Using tree2go is quite straightforward—it only requires a mouse and a bit of creativity. The interface is designed to be fully interactive and as intuitive as possible, with no coding involved. Everything (or almost everything, as far as I can tell) can be edited either at the group level or individually, so there should be very few limitations on the visual style you want to achieve.

The menu on the left contains the main sections for controlling the overall appearance of the tree and its elements. However, by clicking directly on individual items and using the right-click menu, you can access more specific options to customize each one independently.

The tool also supports external resources, such as figures or tables containing species data, which makes it possible to take the visual design even further. However, given the number of customization options, the more complex a figure is, the greater the chance of encountering an unnoticed bug. The integration of modules and features is so extensive that there are inevitably combinations I haven’t even thought to test. As I come across them, I’ll keep fixing them.
